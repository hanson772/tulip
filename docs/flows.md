# 业务流程

## 1. 用户注册与登录流程

```
用户 → 打开首页 → 点击登录按钮
                  ├── 弹出 LoginDialog
                  ├── 切换到"注册"Tab
                  ├── 填写 用户名 + 邮箱 + 密码
                  └── 点击注册
                       ├── API: POST /api/users/register
                       ├── 后端：bcrypt 加密密码 → 创建用户
                       ├── 后端：生成默认 SVG 头像
                       ├── 后端：分配默认 role "user"
                       ├── 后端：签发 JWT（7天有效期）
                       ├── 返回：用户信息 + roles + token
                       ├── 前端：保存到 Vuex + localStorage
                       └── 跳转到首页
```

## 2. 主题创建与发布流程

```
用户 → 首页 → 点击"+" → 创建主题页 (Add.vue)
       ├── 填写标题 + 内容 + 截止时间（可选）
       ├── 添加看法（至少 2 条）
       ├── 保存草稿 → API: POST /api/topics → 状态: draft
       └── 点击"发布"
            ├── 弹窗确认："发布后将进入审核状态"
            ├── 先保存未保存的修改
            ├── API: POST /api/topics/:id/publish
            ├── 后端校验：draft 状态 + 至少 1 条看法
            ├── 状态改为：reviewing
            └── 前端提示："已提交审核，等待管理员审核"
```

## 3. 审核流程

```
管理员 → 首页左侧抽屉 → 控制台 → /console
        ├── Tab：审核
        │    ├── 获取待审核列表 API: GET /api/topics/review
        │    ├── 卡片展示：标题、内容、作者、时间
        │    ├── 快速审核：点击卡片上的"审核通过"按钮
        │    │    └── API: POST /api/topics/:id/review
        │    │         └── 后端校验：admin 角色 + reviewing 状态
        │    │         └── 状态改为 published，卡片从列表移除
        │    └── 查看详情：点击卡片进入 /console/review/:id
        │         ├── 展示：完整标题、内容、标签、看法列表
        │         ├── 点击"审核通过"
        │         │    └── API: POST /api/topics/:id/review
        │         │    └── 成功后返回审核列表
        │         └── 点击返回箭头回到列表
        └── Tab：标签管理
             └── 嵌入 TagManage 组件（embedded 模式）
```

## 4. 支持（投票）流程

```
用户 → 主题详情页 → 查看看法列表
       └── 点击某个看法的"支持"按钮
            ├── API: POST /api/topics/:id/opinions/:id/support
            ├── 三种情况：
            │    ├── 未支持过 → 新增支持
            │    ├── 已支持此看法 → 取消支持
            │    └── 已支持其他看法 → 切换到此看法
            └── 前端刷新支持计数
```

## 5. 评论流程

```
用户 → 主题详情页 → 评论区域
       ├── 发表评论
       │    ├── 输入内容 → 点击发表
       │    ├── API: POST /api/topics/:id/comments
       │    └── 评论即显示在列表中
       └── 回复评论
            ├── 点击某条评论的"回复"按钮
            ├── 输入回复内容
            ├── API: POST /api/topics/:id/comments
            │    └── body: { content, parentId }
            └── 显示在父评论下方（仅一层嵌套）
```

## 6. 收藏流程

```
用户 → 主题详情页 → 点击收藏图标
       ├── API: POST /api/favorites/:topicId
       │    ├── 未收藏 → 新增收藏
       │    └── 已收藏 → 取消收藏
       └── 图标切换实心/空心

用户 → 个人中心 → "我的收藏"Tab
       └── API: GET /api/topics/mine/favorites
```

## 7. 角色分配流程

```
管理员 → 直接调 API：PUT /api/roles/user/:userId
        └── body: { roleIds: [1, 2] }
        └── 示例：为用户同时分配 user + admin 角色

用户重新登录 → API 返回 roles: ["user", "admin"]
             → 前端可见控制台入口
```

## 8. 主题状态流转图

```
                    ┌──────────┐
                    │  草稿    │
                    │ (draft)  │
                    └────┬─────┘
                         │ 用户点击"发布"
                         │ 校验：有看法 ≥ 1
                         ▼
                    ┌──────────┐
                    │  审核中  │
                    │(reviewing│
                    └────┬─────┘
                         │ 管理员点击"审核通过"
                         │ 校验：admin 角色
                         ▼
                    ┌──────────┐
                    │  已发布  │
                    │(published│
                    └────┬─────┘
                         │ 过期（手动或自动）
                         ▼
                    ┌──────────┐
                    │  已过期  │
                    │ (expired)│
                    └──────────┘

说明：
- draft：用户创建后未发布，可编辑
- reviewing：用户提交审核，不可编辑，管理员可见
- published：审核通过，所有人可见，可评论/支持
- expired：已过期，可查看但不可支持
```
